## Краткий отчёт по результатам

### Модели и лучшие промпты

| Модель | Лучший промпт | Результат |
|--------|---------------|-----------|
| **llama-3.2-3b** | v2 | Вызовы работают, но много ошибок: неверные имена банков (Sberbank/Tinkoff), выдуманный курс 70 ₽/$, совет оставить валюту вместо вклада. v3 — имитация результатов без вызовов. |
| **qwen2.5-3b** | v2 | Вызовы работают. Вклады: Тинькофф 17% > Сбербанк 16% — верно. Ключевая ставка vs инфляция — верно. 1000$: неполный вызов (нет курса USD), вывод упрощён. v3 — ошибка: Сбербанк признан выгоднее. |
| **nemotron-3.5-lightning-free** | v3 | Лучший результат. Все вызовы корректны, имена банков русские. Вклады: Тинькофф 17% > Сбербанк 16% — верно. 1000$: вызывает ВТБ, инфляцию, курс — расчёты верные. Биткоин: честно сообщает об отсутствии функции. Есть обрезка по max_tokens. |

### Основные проблемы

- **Неверные имена аргументов**: английские `Sberbank`, `Tinkoff`, `VTB` → «нет данных».
- **Неполные цепочки**: модели часто не вызывают все нужные функции (курс, ставка, инфляция).
- **Преждевременные ответы**: llama-3.2-3b v1 не ждёт результатов, выдумывает числа.
- **Логические ошибки**: qwen2.5-3b v3 неверно сравнивает 16% и 17%.
- **Обрезка ответов**: nemotron v2/v3, qwen v2 — не хватает max_tokens.
- **Сбой после 6 вызовов**: nemotron v2 не выдал ответ на вопрос о вкладах.

### Выводы

1. **Лучшая модель** — nemotron-3.5-lightning-free с промптом v3.
2. **qwen2.5-3b** с v2 — приемлемо для простых запросов, но требует доработки промпта и валидации.
3. **llama-3.2-3b** — не подходит для агента с вызовом функций.
4. **Промпт v2** — оптимален для локальных моделей; **v3** — для облачных.
5. Для стабильной работы необходимо: унифицировать формат вызова, указать русские имена банков, добавить проверку полноты вызовов, увеличить `max_tokens`, ограничить число вызовов.
